# 小壁虎大冒险 🦎

帮小壁虎躲开危险、吃掉萤火虫的手机小游戏。

## 玩法

- 👆 **上滑 / 轻点**：跳起来 —— 躲斧头 🪓、穿过高处的网
- 👇 **下滑**：贴地爬 —— 躲骷髅 💀、钻过低处的网
- 👈👉 **左右滑**：后退 / 前进
- ✨ 吃萤火虫加分，🕸️ 蜘蛛网有缺口，看准再钻
- ❤️ 3 条命，撞到障碍物掉一条

电脑上也可以玩：方向键 / 空格。

## 在手机上安装

1. 用手机浏览器打开游戏链接
2. 浏览器菜单 → **添加到主屏幕**
3. 以后点桌面图标就能玩，像 App 一样，还能离线玩

## 本地运行

```bash
cd gecko-adventure
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
